# 事实、素材与演讲者备注

在涉及政策、数据、真实机构/人物/项目、校园照片或完整讲稿时读取。

## 核对证据

- 为重要事实记录发布单位、标题、发布日期、适用年度/届别、网址和口径。按用户目标年度核查官方来源；未来年度未公布时标为参考规则。
- 保留数据对象、年份、范围和单位；区分人数/人次、项目数/参与比例、院系/全校。缺少可靠数据则省略或待核实。
- 核对照片机构、校区、场景与原文说明。网页发布日期不等于拍摄日期；不凭外观猜测路名、校区或日常动线。
- 保存原始照片及水印、署名和原色。真实场景不使用AI渲染图补齐；无可靠素材时明确占位用途。
- 分别标识训练建议、虚拟案例和实证结论，不从单个故事推导保证结果。
- 未提供的姓名、经历、成绩、奖项、照片等明确占位，不从记忆擅自扩写讲师履历。

## 来源位置

上屏保留简短来源ID与年份，完整标题、单位、日期、URL和照片来源写入备注。来源附录按实际用到的内容分页，可用标题作超链接；保持项目规定字号与行距，不缩字堆满URL。

来源与素材ID保持对应，只列支持当前页面的实际来源。

## 每页备注结构

```text
建议时长：__秒，含互动__秒。
本页核心信息：
口头解释或例子：
互动方式：提问、思考/回答时间、引导与收束。
下一页过渡：
完整来源：来源ID、标题、单位、日期、适用年份、URL。
图片来源：素材ID、机构、校区/场景、原图出处、日期说明、署名/水印。
待补充：仅列确实缺失的个人故事、素材或信息。
```

备注应能支撑分配时长，不能只有关键词，也不将讲稿全文铺在屏幕上。纯训练页注明建议性质即可，不编造外部来源。

涉及个人情况的互动采用自愿思考或纸上记录，不要求公开不必要的成绩、家庭信息。对个体录取概率或未公布政策保留核实边界。
