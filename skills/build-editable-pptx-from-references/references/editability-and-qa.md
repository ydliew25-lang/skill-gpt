# 分层与验收

## 对象约定

| 元素 | 优先对象 | 可承诺的编辑范围 |
|---|---|---|
| 标题、正文、编号、图注、背景字 | 文字框 | 内容、字体、字号、颜色、位置 |
| 线条、箭头、边框、卡片、填写线 | 原生形状/连接线/可编辑符号 | 几何、线宽、填充、方向、层级 |
| 表格 | 原生表格 | 单元格、行列、边框、样式 |
| 数据图表 | 原生图表及可修改数据 | 数据、系列、标签；按工具能力核验 |
| 照片 | 独立图片 | 移动、缩放、替换、可恢复裁切 |
| 纸纹 | 独立图片与底色/叠加层 | 替换、删除、透明度、位置 |
| 透明PNG | 独立位图 | 整体移动、缩放、旋转、替换 |
| 内部线条须可改的图标 | 原生形状或可编辑矢量路径 | 路径、描边、填充，按实际支持说明 |

SVG扩展名本身不证明内部路径可编辑；一个可编辑页码也不能证明正文可编辑。

## 保留构图

记录原图尺寸、关键相对位置、宽高比、文本换行、边距与叠放关系。跨画布重建使用一致坐标缩放，明确区分像素与磅。

文字超出时检查字体、行距、换行、文本框和内边距；不靠截图或缩字掩盖问题。表格实际高度可能因字体度量扩大，须查看末行与页脚。

## 四类检查

- 事实：逐页必需信息、来源/年份、单位、案例标识、个人信息占位。
- 视觉：每页全尺寸查看并对照原图；边缘、遮挡、比例、水印、图注、表格末行和页码。
- 对象：类型、内容、分层、图片来源与表格/图表原生性；PPTX中的整页截图不满足重建要求。
- 讲述：完整备注、互动和过渡、批次与全稿秒数。

最终检查使用导出PPTX重新导入后的预览。合并后检查顺序、页码、备注和附录。只有实际打开目标客户端才宣称在其中验证；结构检查不证明客户端兼容或字体存在。

## 补充结构检查脚本

`scripts/audit_pptx.py` 为只读Python标准库脚本，不代替当前Presentations验证器和逐页视觉检查。替换下方路径占位。

```bash
python3 <skill-directory>/scripts/audit_pptx.py <deck.pptx> \
  --expected-slides 5 \
  --required-table-slides 1,5 \
  --allowed-fonts 'SimSun,Times New Roman' \
  --require-notes \
  --line-spacing 1.5 \
  --output <private-check-directory>/object-audit.json
```

页号为文件内1-based序号，不是画面的全稿页码。仅添加实际需求选项；没有表格要求则省略。读取错误、警告与每页证据。

`--allowed-fonts` 检查全部具体字体声明，包含未使用的主题/版式，不等于最终可见字体集合；主题引用另列。`--line-spacing` 要求有文字段落明确写入倍数，继承样式不会被猜测为满足要求。需要接受主题继承时不要盲用这两个严格选项，改用当前工具的有效样式检查。

行距选项仅覆盖幻灯片页面内的有字段落（含表格），不覆盖备注、母版或独立图表文本。`--require-notes` 只检查备注存在且非空。若用户也要求备注格式、来源完整性或时长，单独核对，不能以这两个选项通过来替代。

全屏图片可能是背景，需结合正文对象和预览判断。对图表字体、主题继承及报告未覆盖项使用当前工具专用检查，不据此声称所有字体或可编辑要求已通过。
