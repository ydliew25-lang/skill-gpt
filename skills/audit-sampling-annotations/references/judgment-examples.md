# 试吃标注复核示例

以下是为复用而编写的模拟对话。以本批字典决定字段名和允许取值，例子用于解释证据要求。

| 原话或可见动作 | 能确认的事实 | 评测时检查 |
| --- | --- | --- |
| 机器人先介绍“低糖”。甲问“酸吗？” | 顾客咨询酸度；“低糖”来自机器人 | 有无把机器人话术归给甲，或给甲补出低酸偏好 |
| 甲：“这块挺脆，就是太咸了，总体还行。”此前确认甲入口 | 口感描述、咸度相对预期偏高、整体中性均属于甲 | 一句话应覆盖多个独立字段。总体取值按字典和原话，不能用方面打分覆盖 |
| 甲问“有更小袋的吗？”单句缺少其他线索 | 至少有规格咨询 | 结合后续“我只要小袋”或“我替朋友问”再判偏好、主体及适用场景 |
| 甲：“不要了。”乙接过样品，随后传来塑料袋轻响 | 甲拒绝，乙接住；品尝者和入口动作均未知 | 同拨可同时有拒绝和接受；核实两人、同一份样品、事件顺序；拒绝原因须另有依据 |
| 乙问“我还能再领吗？” | 追加索样请求，询问领取许可 | 原字典若支持服务咨询，核对第二层语义；若未涵盖，登记字典缺项。再次实际取走及是否同一任务须另查 |
| “和靠门那袋是同款吗？”画面只拍到试吃杯 | 试样可辨，被指零售品身份和同款关系未知 | 只挂起待核的对象及关系；保留咨询。场次固定商品名不能证明被指商品身份 |
| 先说“这个”，随即更正“不是那盒，是左边这盒”，画面可辨 | 有对象更正及最终指向 | 保留旧证据和修订链；明确最终有效记录。若实际画面未提供，区分可核的文字描述与原始视频 |
| 甲说“我等会儿买那盒茶”，当前试样为饼干 | 购买意向属于茶；若不能定位具体品种则保留未知 | 检查主试品、意向商品、支付结果的字段归属 |
| 字典总表允许用拒尝判未品尝，操作细则另要求完整观察 | 两种证据要求会影响相同的品尝记录 | 摘录版本、章节和适用条件；先保留“明确拒绝”。列出按两种口径需改的标签和分母，送裁决 |
| 已记录“甜度强度＝0”；其他场次完全没有确认入口 | 0可能是量表合法值；试后反馈覆盖率的分母可能为0 | 前者按字典保留数值；后者标“不适用（分子0／分母0）”。问过甜度本身不能进入已尝人群 |
