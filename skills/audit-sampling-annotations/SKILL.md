# 商品试吃标注数据评测

以已标注数据为起点，以原始会话为证据，回答三件事：哪些判断可靠，哪些应补或修正，哪些需要补证据或统一规则。默认交付评测报告，保留输入文件。品牌结论、经营建议及商业效果验收属于另一步工作。

## 1. 锁定输入和口径

- 找出原始日志、对应批次的标注表、标注时使用的字典和本次评测标准。记录文件版本、商品和场次、时间窗、真实或模拟、证据形态。若另给新版字典做迁移评测，注明旧版合规性与新版差异。
- 没有原始日志时先做结构检查，标记语义依据和漏标复核待补。缺字典时可核事实和记录链接，枚举、必填与语义取值的正式合规性待核。缺验收阈值时保留实测数。独立标准答案用于正式精确率、召回率等计算。
- 列出完整拨数、拨内顾客身份、原文行数、标签数，注明场次配置是否计入。定位每个工作表或数据文件中代表原句、事件、标签、会话索引及裁决的字段。小批量逐拨全查；抽样时记录总量、样本及选择依据，优先覆盖多人、易混语义、否定／改口、跨商品及未知案例，同时保留普通样本。

## 2. 检查记录与证据链

- 按原始行号、时间或事件ID对齐原文副本。查缺行、多抄、改写、次序、声画来源及发言人；区分排版转义差异与内容变化。检查标签ID唯一，主证据和旁证能定位到原始文件，相应批次和规则版本可回查。跨拨仅允许有明确适用范围的共享场次证据。
- 逐字段查必填条件、类型、单位、枚举、范围及单选／多选。区分合法的0、明确无偏好和未知；逐项校对缺失原因、业务空值及裁决状态。统计全字段时按所有适用字段建分母。核对按拨索引与明细数量。
- 可将数据映射后运行 [结构核对脚本](scripts/check_links.py)，输入与执行方式见 [数据映射说明](references/check-input.md)。原文副本与原始日志须分别从各自材料提取。脚本只覆盖列明的检查，仍须核对适用字典、现场含义及脚本外的字段。

## 3. 按拨做双向语义复核

1. **原文 → 应标信息。** 先通读一拨，结合前后问答、动作和时间顺序，为可标事实写出证据位置、主体、对象及商品角色、阶段、字段、值。记录一条话里的多个事实，以及应留空的子项。再与现有标签对应，查漏标。没有对应字典字段时记录“字典覆盖缺口”，注明建议；不追溯认定为当时的确定错标。
2. **标签 → 原始证据。** 对每项判断回查主旁证，检查指代、多人归属、否定／更正、比较、证据强度和规则版本。逐项验证“能定位原文”和“原文支持此判断”。分清咨询、明示偏好、试后感受、建议与购买意向。只按本批规则映射量表，不以方面分数替代顾客给出的总体评价。
3. **核实事件和去重。** 区分索样、接受、递送到位、实际接住、品尝和支付。区分多次发声、一次任务和多份样品。同一行可支持多个标签，同一份样品可有多个阶段；按具体事件类型与实例计数。分别核人数、拨数、样品份数和咨询事项数。缺少证据时只挂起无法确定的判断。
4. 将发现归为确定误标、漏标、重复、结构／字典缺项、源资料缺失或规则待裁决。每项保留原话、行号或时间、标签ID、现值、依据、建议及影响。争议样本和已确认合理案例分别列出。需要边界参照时看 [模拟判例](references/judgment-examples.md)。

## 4. 按可评测范围计算指标

- 对照用户给定的每项指标，标明适用、局部可核、待评测或不适用。回传、设备、交易等超出本次标注评测的项注明所缺输入或范围。发现本批重点字段未纳入标准时，单列补充检查，并标明它的依据。
- 原文保留率用应收原文行数作分母；证据可追溯率用输出标签数作分母并检查证据和规则版本；无依据标签率按给定标准的输出范围计；事件重复率按同一业务事实的超额记录计。部分字段或部分拨次通过时只报告实查范围。
- 有独立、已裁决的标准答案时，冻结匹配键（会话、主体、商品角色及对象、阶段、字段、取值，必要时证据锚点或事件时窗），多选拆项，一对一匹配。按字段报TP、FP、FN、精确率 TP/(TP+FP)、召回率 TP/(TP+FN)、F1=2TP/(2TP+FP+FN)。分母为零的对应指标记不适用，并报样本数。规则未决项单报数量及是否纳入分母；没有独立标准答案时提供本轮复核计数及案例，暂缓正式验收判断。
- 明示偏好覆盖率按有可核偏好的有效会话／全部有效会话计算。试后反馈覆盖率按有有效评价的确认品尝会话－商品／确认品尝会话－商品计算。同人、同商品的体验依据先核对，再按标准去重。报告未知数。对每个比例保留分子、分母、单位、窗口、版本及抽样范围，并说明阈值是建议还是已确认。

## 5. 交付评测与复测清单

用 [Markdown 报告模板](assets/report-template.md) 写清结论、量化结果、带证据的错漏项、待裁决事项和复测条件。建议优先处理会改变顾客归属、商品归属、品尝／购买状态或统计分母的问题。若用户授权修订，保留原值和规则版本，记录裁决、重算受影响的标签与指标，再复查同类样本。
