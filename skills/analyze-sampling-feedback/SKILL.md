# 商品试吃品牌反馈分析

从品牌需要做的决定出发，让报告回答三个问题：顾客具体表达了什么，有多少人或多少拨表达了同样的反馈，这些证据能支持品牌做什么。

## 准备输入

读取本次商品和场次的已标注数据、对应版本的字段与取值规则，以及可以通过会话号、时间或行号回查的原话或现场记录。接受同一工作簿中的「逐条原文」「标签明细」等工作表。记录商品、门店或场次、数据版本和真实或模拟属性。只有已标注表时，使用表内可核查的证据，指出哪些判断需要补回原声；只有原始日志时，先取得逐句标注，可衔接「商品试吃数据评注」Skill。对可识别的顾客、商品和场次分别统计。

## 执行六步分析

1. **确定品牌问题。** 写清品牌方要调整的商品、包装、陈列、导购或活动环节。将问题限定到对象、阶段和可观察结果。例如，已明示想买本款商品的顾客，问到销售位置时能否得到可执行的指引？
2. **先定义统计口径。** 按本次数据字典选字段，逐项写明纳入条件、单位、去重键、分子、分母与未知项。试后总体喜欢率，用同一顾客对同一商品的「已确认品尝且给出有效总体评价」人次作分母，其中明确喜欢的人次作分子，另报已尝但未评的人次。记录意向的时间点，区分询价、明示想买、实际支付。
3. **按问题筛证据、去重。** 对齐会话、说话人、需求归属人、商品、试吃或零售阶段、标签及取值、时间和原话。从同拨多人中分别识别发言人。统计主题覆盖时，同拨同主题计一拨；统计咨询事项时，同一人在同次会话对同款商品反复确认同一件事计一项，问价和问位置分两项；评估逐轮答复时保留每轮。分别标记未知、未提及和明确拒绝。
4. **汇总数量，回看选择过程。** 依单位报告人数、拨数、咨询事项数、人次或标签条数。按会话、顾客和商品串起提问、答复、评价、意向及后续动作。优先比较评价相近但最后选择不同的会话。涉及多个主题时注明交集和去重后的总数；子集与全场分别报告。
5. **写出发现及适用范围。** 引用具有代表性的原话和日志位置。分别说明顾客明示、现场观察和待验证的解释，为各问题给出「可确认」「待验证」或「暂不可判断」。购买结论需要交易证据，效果归因需要可比条件。把小样本结论限定在本场，把模拟数据的结果标为方法演示。
6. **明确动作、负责人和验证方式。** 每项优先发现配上具体改动、负责方和下次复测指标。尚未分工时标明建议负责方。下一次沿用相同口径；要验证成交或复购时列出需要关联的记录。复算分子、分母与去重数量，对照会话、发言人和原文。分母为零填「暂不可计算」并说明原因。

## 交付品牌反馈报告

先简述样本范围和本次最有证据支持的发现，再使用[七列交付模板](assets/brand-feedback-table.md)，逐字沿用模板中的七个列名和列序，每行呈现一项发现。即使用户要求精简，也优先压缩单元格里的文字。将分子、分母写成有具体含义的数量并标出单位，例如「获得具体位置答复 0 项／位置咨询 1 项，涉及 1 拨顾客」。需要拆解指标时在表后补充明细，列名写清对象、结果和单位。参考[开口松子模拟案例](references/pine-nut-example.md)核对全场与购买意向子集的统计差别。
