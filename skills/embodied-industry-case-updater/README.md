# 具身智能合作案例增量更新 Skill

用途：把指定时间窗口内的具身智能行业合作/落地新闻，经过来源核验、证据边界判断和去重后，增量写入用户提供的 Excel 数据库。

## 加载
在支持自定义 Skill 的 AI 环境中，按该环境的实际导入方式加载整个文件夹；也可以让具备网页检索和电子表格工具的助手读取 `SKILL.md` 及其引用的 `references/schema.md` 执行。保留相对路径，不依赖固定平台菜单。

## 使用
上传需要更新的 `.xlsx` 文件，然后说：
“使用这个 skill，更新最近 5 天的具身智能合作案例，去重后写入‘合作案例’子表，新内容标红。”

## 输入要求
- 最佳：提供现有 Excel 数据库。
- 指定检索时间范围；不指定时可使用“最近 N 天”。
- 可选：指定公司、场景、地区或来源要求。

## 输出
更新后的 Excel 文件，以及新增/更新/重复情况的简短说明。
