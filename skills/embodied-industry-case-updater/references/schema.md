# 默认数据结构

| 字段 | 规则 |
|---|---|
| 公司 | 具身智能公司/主体 |
| 合作方/对象 | 外部合作主体，具名优先 |
| 发生期间 | 实际事件日期 |
| 具身能力模块 | 标准模块标签，以｜分隔 |
| 具体功能能力 | 可验证的具体能力 |
| 任务/场景 | 业务任务和场景 |
| 产品/系统 | 型号/模型/平台/方案 |
| 阶段 | 合作/研发/PoC/试运行/部署/规模运营 |
| 自主/人工参与 | 自主程度、遥操作、接管；未知则明确未知 |
| 公开指标 | 量化指标，目标值需标注 |
| 证据边界 | 证明与未证明内容 |
| 来源1 | URL |
| 来源2 | URL，可空 |
| 来源性质 | 官方/权威媒体/行业媒体/转载等 |

## 推荐检索式

- `YYYY MM DD 具身智能 战略合作 机器人`
- `YYYY MM DD 人形机器人 部署 工厂`
- `YYYY MM DD 机器人 联合研发 场景验证`
- `公司名 合作方 机器人 YYYY`
- `company humanoid robot partnership China YYYY`
