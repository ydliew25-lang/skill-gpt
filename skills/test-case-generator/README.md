# 测试用例生成 Skill

将产品需求、业务流程和已确认的技术约束，转成可执行、可判定的中文测试用例。

## 文件

- [SKILL.md](SKILL.md)：触发场景、六步流程、六列表格和交付规则。
- [机器人教学示例](references/retail-robot-example.md)：场景组合、计时起点、状态继承与完整用例。
- [质量检查清单](references/review-checklist.md)：检查覆盖、可执行性、能力边界和预期结果。
- [测试表格模板](assets/test-case-template.md)：可复用的六列 Markdown 模板。

## 使用

在支持自定义 Skill 的 AI 环境中，按其实际方式加载整个文件夹；或让能够读取文件的助手读取 `SKILL.md` 及其引用材料。

> 使用 test-case-generator，根据我提供的产品需求和设备能力，梳理场景矩阵，再输出独立完整的六列测试用例。未知能力与参数标为待确认。

案例中的商品、超时和动作配置已泛化为教学示例。真实项目需替换为已确认参数；本文件包不提供设备控制或自动化测试执行能力。
