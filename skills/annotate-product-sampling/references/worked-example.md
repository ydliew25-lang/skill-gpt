# 黑芝麻酥试吃评注示例

以下为演示片段，所有行同属批次 B、会话 B03。活动配置说明试样为独立包装的一块黑芝麻酥，零售商品每袋六块。将示例用于对齐取值粒度，处理新批次时使用新批次自己的证据。

| 原文 ID | 来源 | 完整原文 |
| --- | --- | --- |
| R01 | 录音·顾客甲 | 这个甜吗？ |
| R02 | 录音·机器人 | 这是本场试吃的黑芝麻酥。 |
| R03 | 视频 | 顾客甲接走一块，转身递给乙。 |
| R04 | 视频 | 顾客乙拆开包装，咬了一口。 |
| R05 | 录音·顾客乙 | 芝麻味挺浓的。这一袋六块，我一次吃不完。 |
| R06 | 录音·顾客甲 | 那我今天先拿一袋吧。 |

| 主证据／旁证 | 判断归属和对象 | 字段与细项 | 可记录的取值或状态 |
| --- | --- | --- | --- |
| R01 | 甲，本场试样 | E10 咨询关注属性 | 甜度。甲没有表达自己想要多甜。 |
| R03 | 甲接走试样，之后递给乙 | E01 行为事件、E02 确认依据 | 分别记“确认取走”“感知确认”。原文中的两次交接都保留，领取人为甲，实际品尝人为乙。甲的入口缺可见证据。 |
| R04 | 乙，本场试样 | F01 品尝状态；E01 确认品尝 | F01 已品尝、试后；行为事件分行标注。 |
| R05／R04 | 乙，本场试样 | F02 感知风味 | 芝麻味，程度原词“挺浓的”，体验依据为品尝已确认。方向未表露；总体喜好未提及。 |
| R05 | 乙，零售装 | F07 商品包装规格·每袋件数 | 每袋六块对其单次食用偏多，负向。理想件数未提及。 |
| R06／本拨上下文 | 甲，零售整袋 | F10 购买意向 | 打算本次购买；证据是顾客本人表达的计划。 |

实际输出时，每个正式字段独占标签行；表中并列字段用于展示同一证据的多种用途。R02 保留在原文表并写明“机器人介绍品名，未答甜度”。乙的包装规格反馈和甲的购买计划分别成立，不能据此判断乙本人愿意购买或甲也嫌六块太多。
