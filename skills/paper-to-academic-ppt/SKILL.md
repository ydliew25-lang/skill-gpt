# 论文转学术主题 PPT

1. **明确报告任务。** 读取用户指定的最新版论文、附件和已有演示。记录听众、时长、重点、可用材料范围、希望交付的内容及版式要求。把论文收束为一个报告问题与一句预期回答。已有标题时沿用，并让结论直接回应它。
2. **按听众理解的顺序组织论证。** 提取概念、主张、证据与关键限制，安排导入、理论或分析、个案与收束。每页承担一个任务。用 [逐页规划模板](references/slide-plan.md) 建立页码、主张、证据、出处、呈现方式和时长的对应关系。预算包含用户要求的过渡与讨论，页数随证据密度和时长调整。
3. **核证后写上屏内容。** 比对引文、版本、页码或档号。区分直接引语、转述和解释，按材料所能支持的强度表述。页底写该页证据支持的判断。用户限定使用范围时按指定来源工作。把初稿中的个人分析转换为报告主张，引用按发表状态与用户要求取舍。史料、沿革或现有图表容易混淆时，使用 [证据与验收](references/evidence-and-review.md)。
4. **按表达任务制作可编辑页面。** 用时间轴交代先后，用结构图说明机制，用引文页呈现证据。根据已有演示或参考样式统一页眉、页脚、字号、颜色与间距。重建图表时逐层制作原生文字框、形状、线条与连接线，保留原图有意义的关系、箭头方向和阅读顺序。按当前可用的演示制作流程导出和验证。
5. **写出有层次的收束。** 个案小结说明该个案怎样回答前面的理论问题和材料支持的范围。分节总结提炼各部分的核心判断。总体结论直接回答报告标题，解释各主张之间的关系及个案对理论的推进。按篇幅决定分开呈现或合并呈现。
6. **对齐口播与页面。** 为关键页补上讲述要点、过渡、时长与完整出处。根据用户反馈逐页修改，检查受影响的引文、图表、结论与备注。插页或调序后核对目录、章进度、页码、交叉指引和讲述总时长。
7. **校验后交付。** 按 [证据与验收](references/evidence-and-review.md) 核对证据、放映可读性和对象编辑性。交付用户要求的提纲、演示或讲稿。交付可编辑 PowerPoint 文件时，检查实际导出版本。用简短文字说明有实质影响的改动、材料范围与未验证项。
