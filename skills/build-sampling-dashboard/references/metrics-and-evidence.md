# 指标与证据模板

## 按业务问题填写一张指标卡

| 字段 | 需要填写的内容 |
|---|---|
| 决策与结论 | 谁要决定什么？用一句话写出观察结果，再写一项可在下一场验证的行动 |
| 观察范围 | 授权角色、门店、场次、SKU、时区、时间窗、已发布版本 |
| 统计单位 | 拨、同场可区分人次、样品份数、反馈份数、咨询事项或费用。写清参与者标识适用的范围 |
| 分子与分母 | 写出各自的纳入条件、成员标识集合、去重键和数量。若无有效分母，显示「暂无可计算比例」 |
| 未知与重叠 | 明确记录的零、证据缺失、仅知下限、待与图像确认分别处理。多选值允许同一成员落入多个分支 |
| 回查与修订 | 关联原话、观察记录及时间、表名和行号。说明更改取值后哪些页面和导出需要刷新 |

## 三个经常混用的指标

| 问题 | 建议口径 | 边界 |
|---|---|---|
| 哪些接触者对本品有兴趣？ | 在本场接触拨中，对明确归属本品的主动询问、索样或明示想买进行拨号去重 | 仅记录到其他商品或机器人本体的兴趣时，单列。未记录兴趣信号的人群只能归入「未记录」 |
| 有多少可用反馈？ | 按标注规则对「场次、拨、本人、本品」去重，另列「确认已尝且有反馈」子集 | 「甜吗？」是甜度咨询，「我尝了，太甜」能支持试后甜度评价。一次试吃可贡献多个维度 |
| 是否调整样品量或活动时段？ | 从领样事件统计独立领出，从台账核查备样、补入、报废、退回、结余；按首次参与或事件时刻归段 | 有人索样或同伴分食，不能据此增加独立领出量。记录跨度、可服务时长与门店营业时长分别保留 |

**写法示例。** 一场模拟试吃共有 12 拨、17 个可区分人次；5 拨至少有一人主动了解本品。页面可写「接触的 12 拨中，5 拨表现出兴趣（41.7%）」。另一栏可同时显示「可确认的有效商品体验反馈 0 份」。点兴趣图分支看本品询问或索样证据，点价格只看问价标注。顾客问价后离开，购买结论仍须有后续凭证。

**同拨意见相反。** 同一拨 A 说「正好」，B 说「有点甜」。分别保留说话人和原句，以可区分人次统计时两人各记一次；按拨统计时可报告「该拨有两种评价」。若不同口味/商品导致指代不明，转入复核后再作具体商品归属。显示饼图前检查各分支是否互斥且覆盖所用分母。

**对齐三个时间口径。** 「本时段首次参与拨数」按首次参与归段；「时段内有互动的拨数」按该段出现的拨号去重，同一拨可跨段；「有效反馈」按规则约定的首次有效证据归段。记录采用半开区间或等价的无重叠边界，保留末段实际长度。只有可相加的口径才用分段和与整场核对。
