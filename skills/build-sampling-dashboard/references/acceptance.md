# 端到端验收

挑两家会重复使用相同拨号的门店、一个低样本时段和一个无样本维度。每轮用实际页面按钮操作，记下预期、实际和对应来源；先用以下路径发现错误，再扩展到项目中的全部角色和门店。

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 来源接入 | 对照门店资料清单，抽查每张表首、中、末行；核对日志时间和报告统计 | 每份报告、每张工作表与正确的场次对应，原始句和标注可通过编号互查。「至少」「未知」等限定保留 |
| 总览至明细 | 从品牌总览的用户反馈结论进入专题，点击一个甜度分支，打开一条原话，再返回 | 结论在上、依据按支持力排列，分支的成员和据此列出的明细一致；多条标注可能对应一拨。返回恢复原筛选 |
| 父主题与叶维度 | 依次选择「价格与购买」「价格」「购买意向」，各下载一次 CSV | 父级覆盖授权子维度；叶级结论、行、字段和下载内容对应单一维度。可以保留行号、门店、时间等回查字段 |
| 范围与统计 | 逐店比对分子分母，切换时段；检查同人多次表达、同拨多人与未知值 | 分母与页面所述人群一致。筛选为空显示 0 条或暂无可计算比例。同行形态与居住情况各用各的证据 |
| 内部复核 | 修改一个待核指代，保存草稿，切另一门店和外部账号，再发布 | 仅内部本店可见未发布修改；发布后对应版本可回查。原日志及历史报告保持可追溯 |
| 权限与下载 | 逐角色点击下载面板，实际下载 CSV、报告以及内部可见的整场附件 | CSV 内容、字段和条数与页面一致；报告角色、商品、日期和门店正确。内部原件切店后随之切换，验证字节或来源清单的摘要值 |
| 帮助与账号 | 打开帮助、账号信息、更多操作，最小化后恢复，退出后重新进入 | 常见问题能找到联系入口；资料与操作入口独立；恢复时保留上下文，退出结束当前演示会话 |
| 交付状态 | 从交付入口打开当前版本，在目标视口重复一条主路径 | 导航可操作、长表可滚动、中文图例清晰、真实点击触发下载。区分本地验证、正在发布和已发布 |

若是既有平台的小改动，先测变更入口及它共用的数据或组件，再测跨角色路径。真实账号平台还要用无权账号访问跨店记录及直接文件链接，核验服务端拒绝越权请求。演示账号模式的切换测试仅能验证原型表现。
