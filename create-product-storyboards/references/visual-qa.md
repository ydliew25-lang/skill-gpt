# 画面与验收

## 出图前锁定

- 记录产品轮廓、比例、关键部件、安装位置、颜色和材质，列出跨镜必保留项。为界面产品记录显示区域、关键控件位置、确定的文案、页面状态和反馈。
- 记录工位或页面的相对位置，以及人、产品、道具和通道之间的关系。用实拍或界面截图锚定结构与操作关系，用风格参考锚定线条、配色、光线和精细度。
- 按用途选风格。写实铅笔淡彩可用细线、轻纸纹、低饱和色、真实透视与接触阴影。材质区分服务于辨认部件，背景淡化以突出动作。

## 检查画面

| 维度 | 检查方式 |
| --- | --- |
| 单镜清晰 | 暂时遮住图注。确认能指出谁在何处、对什么做了什么。精确角色编号、触发条件和失败信息可在图注里写清。 |
| 接触或触发 | 实物查手、工具、货物与承托面的接触、间隙和遮挡。界面查用户操作的控件、前后状态和系统反馈。 |
| 外形与空间 | 核对关键部件、位置、朝向和相对尺度。必要时拉宽或换机位，让动作触点与关键结构同时可见。 |
| 相邻镜头 | 并排核对同一物件、工位或界面；检查前镜结果能否直接接入后镜起点，交接角色和位置能否对上。 |
| 异常分支 | 核对触发条件、处理方、重试、恢复或接管的路径。两个状态画面相似时用简短的图注标明状态差异。 |
| 示意边界 | 逐项标注未定的摆位、工装、产品结构或界面。确定的实物细节以用户提供的实拍、结构资料或界面为依据。 |
| 交付尺寸 | 用实际阅读尺寸看动作触点和文字。图与图注放在一起，保持配对镜头完整；处理跨页表头、裁切或留白。 |

## 常见修订

- 形态画漂或关键部件缺失时，回到已确认的本体或界面参考，检查所有入镜画面。优先改动受影响的局部。
- 动作交代模糊时，将支撑、工具触点或结果状态拉近；仍被遮挡时换角度或拆成相邻两镜。
- 流程更新时，对照新旧镜头清单定位新增、移除与变化的镜头，检查示意图和交接文字。保留用户已经确认的其它特征。
