# 产品场景分镜制作

## 明确交付范围

1. 确认目标读者、他需要看懂的动作或决策、场景起止点和用户指定的交付形式。用户只需要镜头脚本时，交付镜头表。用户要求绘制时，用可用的视觉能力完成相应插图并按所需格式交付。
2. 读取当前版本的需求和用户旅程。遇到 PDF 中嵌入图片的工作流，查看页面或提取流程图，按图中的角色、箭头和分支核对。在资料有冲突时，采用各维度的当前确认来源，明确待核对的冲突。
3. 用流程资料确定顺序、角色、触发、交接和异常。用实拍、结构资料与截图确定产品外形、部件、操作触点和空间关系。用用户选定的分镜或样图锁定画风和排版。
4. 记录资料来源与版本。基于已确认部分完成草稿，在相关镜号标出待确认项。画面需要示意时，在图注注明示意范围。只有关键缺口会改变整个方案、角色分工或主要动作时，才针对该缺口提问。

## 拆镜与绘制

1. 按最新流程建立镜头清单。逐镜写明触发、执行角色、对象、可见动作、起始状态、完成状态、人工或系统配合及证据来源。每镜聚焦一个可观察变化。关键交接和状态变化可编号为 04a、04b，条件分支放在触发点附近并标注分支条件与去向。
2. 对每个项目记录跨镜必保留的特征。场地复杂时先用总览交代工位、位置和角色，再用中景交代动作，用特写显示接触点、状态或完成结果。界面流程可以沿用同一视角展示前后状态。
3. 用代表性的动作和细节样图校准产品外形、道具比例、景别和画风，然后逐镜绘制。用户要求先审样时按其节奏交付。补画或局部修订时以已确认图片为基准，保留与当前变更无关的图文和排版。
4. 绘制成稿前按 [画面与验收](references/visual-qa.md) 检查构图、可见动作、实物或界面一致性和跨镜衔接。使用 [可复制模板](references/templates.md) 生成项目简表、镜头清单、单镜画面描述和验收记录。

## 修订与交付

- 流程变化时，先从新流程重新确定受影响的镜号、角色、交接、触发、条件和结果，再核对相关总览、前后镜、图注及动作说明。实物或画风变化时，核对所有涉及该产品或风格的镜头和总览。
- 按用户指定格式交付。正式图文分镜可用可编辑 Word，排为「镜头与插图｜产品或系统动作｜人员或外部配合」。状态、话术或时长等字段按场景和用户要求添加。沿用已有文档时保持既有版式。
- 逐镜检查图、动作说明、条件和交接一致。按实际交付尺寸核对小图、表头、图注和跨页。交付时指出与使用有关的示意范围或待确认点，并如实说明已完成的图文范围。
